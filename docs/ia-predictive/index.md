# IA prédictive : analyse et modélisation de données

Travaux pratiques de troisième année du BUT informatique, sur l'analyse de données et
l'apprentissage automatique.

## Un premier TP, en test

Un seul TP est publié pour l'instant, pour valider le rythme et la qualité de conversion
avant de convertir les neuf autres. Contrairement au module [IA générative](../ia-generative/index.md),
ce TP ne dépend d'aucune clé API : il s'exécute entièrement en local avec des bibliothèques
Python courantes (pandas, scikit-learn, matplotlib), et son code est **vérifié par le
harnais du site** au même titre que les TP d'[outils fondamentaux](../outils-fondamentaux/index.md).

## Les séances

| Séance | Sujet | Ce que vous saurez faire |
|---|---|---|
| [TP1](tp1-pandas.md) | Manipuler des données avec pandas | charger, sélectionner, filtrer, transformer, agréger, visualiser un jeu de données |

D'autres séances (GeoPandas, clustering, réduction de dimension, classification,
XGBoost, régression, séries temporelles, prétraitement, explicabilité et causalité,
théorie de l'information) viendront compléter ce module selon la même méthode.

Ce TP n'a pas encore de QCM d'auto-évaluation ; c'est signalé sur sa page.
